# ⏰ Таймер обратного отсчёта (Node.js)

Консольное приложение, которое ждёт заданный промежуток времени и затем
пишет в консоль, что таймер прозвонил. Пока приложение работает, оно
ничего не выводит — сообщение появляется ровно в момент срабатывания.

Внешних зависимостей нет, достаточно установленного Node.js.

## 📁 Структура проекта

```
4_dfiz_timer/
├── index.js            # точка входа: аргументы → setTimeout
├── parse-time.js       # разбор времени в миллисекунды
└── parse-time.test.js  # тесты разбора (node --test)
```

## 🚀 Использование

```bash
node index.js <секунды>
node index.js <число> <единица> [<число> <единица> ...]
node index.js 1ч 5м 10с
```

### Примеры

```bash
$ node index.js 5
# через 5 секунд:
Таймер прозвонил

$ node index.js 2 минуты
Таймер прозвонил

$ node index.js 1 час 5 минут 10 секунд
Таймер прозвонил

$ node index.js 1h 5m 10s
Таймер прозвонил
```

## 📋 Форматы времени

| Формат                | Пример                              | Что значит          |
|-----------------------|-------------------------------------|---------------------|
| одно число            | `node index.js 30`                  | 30 секунд           |
| пары «число + единица»| `node index.js 2 минуты 30 секунд`  | 2 мин 30 с          |
| слитно                | `node index.js 2ч30м`               | 2 ч 30 мин          |
| латиницей             | `node index.js 1h 5m 10s`           | 1 ч 5 мин 10 с      |

### Доступные единицы

| Единица                        | Варианты написания                | Миллисекунды |
|--------------------------------|-----------------------------------|--------------|
| секунды                        | `секунда`, `секунды`, `секунд`, `с`, `сек`, `s`, `sec`, `second`, `seconds` | 1000 |
| минуты                         | `минута`, `минуты`, `минут`, `м`, `мин`, `m`, `min`, `minute`, `minutes`    | 60 000 |
| часы                           | `час`, `часа`, `часов`, `ч`, `h`, `hr`, `hour`, `hours`                    | 3 600 000 |

Регистр не важен: `1 ЧАС`, `1H` и `1 час` работают одинаково.
Дробные значения допускаются: `1.5 часа` и `1,5ч` — это 90 минут.
Пары можно писать слитно (`1ч5м`) или через пробел (`1 ч 5 м`).

## ⚙️ Как это работает

1. `process.argv.slice(2)` отбрасывает путь к `node` и путь к скрипту,
   оставляя только аргументы пользователя.
2. `parseTime` склеивает аргументы в одну строку, приводит её к нижнему
   регистру и заменяет запятую на точку.
3. Если строка — одно число, оно считается количеством секунд.
4. Иначе регулярка находит пары «число + единица» (слитно или через пробел),
   каждая переводится в миллисекунды через `UNIT_TO_MS` и суммируется.
5. Хвост, не попавший ни в одну пару (`1 час 5`), считается ошибкой.
6. Итог проверяется на предел `setTimeout` (`2_147_483_647` мс ≈ 24,8 дня)
   и передаётся в `setTimeout`; в колбэке печатается сообщение.

## 🛡️ Обработка ошибок

Приложение пишет причину в `stderr` и завершается с кодом `1`, если:

- аргументы не переданы вообще;
- значение не является числом (`abc`, `Infinity`);
- число отрицательное;
- для числа не указана единица измерения (`1 час 5`, `5 6`);
- указана единица без числа (`час`);
- единица измерения неизвестна (`1 неделя`);
- итоговое время больше предела `setTimeout`.

Примеры:

```bash
$ node index.js -5
Ошибка: время не может быть отрицательным ("-5")

$ node index.js 1 час 5
Ошибка: не удалось разобрать "5"

$ node index.js 5 6
Ошибка: для "5 6" не указана единица измерения

$ node index.js 1 неделя
Ошибка: неизвестная единица измерения "неделя"

$ node index.js час
Ошибка: для "час" не указано число
```

## ⚠️ Ограничения

- Уведомление только через консоль: если не смотреть в консоль,
  срабатывание можно пропустить. Другие способы уведомления появятся позже.
- `setTimeout` гарантирует «не раньше», поэтому реальная задержка может быть
  на несколько миллисекунд больше заданной.
- Максимум — около 24,8 дня: большее время `setTimeout` не принимает.

## 🧠 Используемые концепции

- **`process.argv`** — аргументы командной строки.
- **`setTimeout`** — отложенный вызов колбэка.
- **`Map`** как словарь «единица → миллисекунды».
- **Исключения** (`throw` / `try...catch`) для проверки входных данных.
- **`process.exit(code)`** — корректный код возврата для shell и CI.
