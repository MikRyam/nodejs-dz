# ⏰ Таймер с системными уведомлениями

Консольный таймер обратного отсчёта, который по завершении показывает
системное уведомление: заголовок, текст с длительностью, иконку и звук.
Работает на Linux, macOS и Windows — нужный механизм уведомлений
выбирается автоматически.

Это доработка таймера из задания `4_dfiz_timer_2`: логика разбора
времени и отсчёта осталась прежней, а проект стал полноценным
NPM-пакетом с внешней зависимостью.

## 📁 Структура проекта

```
7_timer_notifications/
├── index.js            # точка входа: аргументы, таймер, обработчик 'done'
├── parse-time.js       # превращает аргументы в миллисекунды
├── timer.js            # таймер обратного отсчёта на EventEmitter
├── notify.js           # системное уведомление через node-notifier
├── assets/
│   └── timer.png       # иконка для уведомления
├── test/
│   ├── parse-time.test.js
│   ├── timer.test.js
│   └── notify.test.js
├── package.json
└── package-lock.json
```

`node_modules/` в репозиторий не попадает — он создаётся при установке
зависимостей.

## 🚀 Установка и запуск

```bash
cd 7_timer_notifications
npm install
```

Запуск:

```bash
npm start -- 5
```

или напрямую:

```bash
node index.js <время>
```

Можно передать просто количество секунд:

```bash
$ node index.js 5
# через 5 секунд в консоли:
Таймер прозвонил
# и системное уведомление «Отсчёт на 5 секунд завершён»
```

Или составное время с единицами измерения:

```bash
$ node index.js 1 час 5 минут 10 секунд
$ node index.js 10м 30с
$ node index.js 1ч 2м 3,5с
$ node index.js 01:05:10   # 1 ч 5 мин 10 с
$ node index.js 05:10      # 5 мин 10 с
```

## 📋 Поддерживаемые единицы

| Единица      | Варианты записи                          |
|--------------|------------------------------------------|
| Миллисекунды | `мс`, `ms`                               |
| Секунды      | `с`, `сек`, `секунда`, `секунды`, `секунд`, `s`, `sec`, `second(s)` |
| Минуты       | `м`, `мин`, `минута`, `минуты`, `минут`, `m`, `min`, `minute(s)` |
| Часы         | `ч`, `час`, `часа`, `часов`, `h`, `hour(s)` |
| Дни          | `д`, `день`, `дня`, `дней`, `d`, `day(s)` |

Дробные значения разрешены: `1,5с` — это 1500 мс.

## 🔔 Как работает уведомление

В момент срабатывания таймера `index.js`:

1. печатает «Таймер прозвонил» в консоль;
2. подаёт терминальный bell (`\x07`);
3. вызывает `notifyTimerDone()` из `notify.js`.

`notify.js` передаёт в `node-notifier` заголовок, текст, иконку и
флаг звука. Пакет сам определяет ОС:

| ОС      | Механизм |
|---------|----------|
| Linux   | `notify-send` через DBus (GNOME, KDE и другие среды) |
| macOS   | Notification Center |
| Windows | Toast-уведомления (SnoreToast) |

Текст уведомления собирается из длительности: `90_000` мс →
«Отсчёт на 1 минута 30 секунд завершён».

Звук: на macOS и Windows используется возможность `node-notifier`,
на Linux дополнительно запускается `canberra-gtk-play -i
alarm-clock-elapsed`, если он установлен. Терминальный bell слышен
в любом случае.

### Почему `node-notifier`, а не `notify`

В уроке упоминается пакет `notify`, но опубликованный в npm
`notify@0.1.0` — это нативный C++-модуль 2011 года только для
GNOME/libnotify:

- его `preinstall` использует удалённый `node-waf`, поэтому сборка
  не выполняется;
- `require('notify')` падает с `ERR_DLOPEN_FAILED:
  libgtkmm-2.4.so.1`;
- macOS и Windows он не поддерживает.

`node-notifier` решает ту же задачу и как раз адаптируется под ОС,
поэтому выбран он. Наружу работа с уведомлениями спрятана в свой
модуль `notify.js` — остальной код от конкретного пакета не зависит.

## 🛡️ Обработка ошибок

При некорректном вводе приложение печатает сообщение и завершается
с кодом `1`:

```bash
$ node index.js
Использование:
  node index.js <секунды>
  ...

$ node index.js 5 парашютов
Ошибка: неизвестная единица времени "парашютов"

$ node index.js -5
Ошибка: время не может быть отрицательным
```

Если системное уведомление показывать некуда (нет графической сессии,
DBus или демона уведомлений), приложение не падает: печатает
предупреждение и завершается штатно. Консольное сообщение и bell при
этом остаются.

## 🧪 Тесты

```bash
npm test
```

Проверяются:

- разбор простого и составного времени, формат часов и ошибки ввода;
- срабатывание и остановка таймера;
- формирование текста уведомления и его опций (`title`, `message`,
  иконка, звук);
- обработка ошибки демона уведомлений.

Тесты уведомлений подменяют отправку, поэтому реальные системные
уведомления при `npm test` не появляются.

## ✅ Требования

- Node.js 22.22.2+ (требование `node-notifier@12`);
- Linux с `notify-send`/DBus, macOS или Windows — для показа уведомлений.
