# 🧮 Консольный калькулятор на EventEmitter

Переработанная версия модульного калькулятора: вместо прямого вызова
функций используется событийная модель на базе встроенного модуля
Node.js `events`.

`index.js` больше не знает, **как** считаются числа. Он лишь публикует
событие (`emitter.emit('add', a, b)`), а модули операций **сами
подписываются** на нужные события и выводят результат в консоль.

Для пользователя ничего не меняется — команда запуска та же.

## 📁 Структура проекта

```
3_calcevents/
├── emitter.js      # общий экземпляр EventEmitter (синглтон)
├── index.js        # разбор аргументов и emit события
├── add.js          # слушатель события 'add'
├── subtract.js     # слушатель события 'subtract'
├── multiply.js     # слушатель события 'multiply'
└── divide.js       # слушатель события 'divide'
```

## 🚀 Использование

```bash
node index.js <число1> <число2> <операция>
```

### Примеры

```bash
$ node index.js 5 6 add
11

$ node index.js 10 3 subtract
7

$ node index.js 4 5 multiply
20

$ node index.js 10 2 divide
5
```

## 📋 Доступные операции

| Событие    | Описание   | Пример                          |
|------------|------------|---------------------------------|
| `add`      | Сложение   | `node index.js 5 6 add` → `11`  |
| `subtract` | Вычитание  | `node index.js 10 3 subtract` → `7` |
| `multiply` | Умножение  | `node index.js 4 5 multiply` → `20` |
| `divide`   | Деление    | `node index.js 10 2 divide` → `5` |

## ⚙️ Архитектура

```
┌─────────────┐   emit('add', 5, 6)   ┌───────────────┐
│  index.js   │ ────────────────────► │   emitter.js  │
└─────────────┘                       └───────┬───────┘
                                              │ on('add', …)
                                              ▼
                                      ┌───────────────┐
                                      │    add.js     │
                                      │ console.log   │
                                      └───────────────┘
```

- `emitter.js` создаёт **единственный** экземпляр `EventEmitter`
  и экспортирует его. Node.js кэширует модуль, поэтому все, кто делает
  `require('./emitter')`, получают один и тот же объект — иначе события
  «улетали бы в пустоту».
- Каждый модуль операции (`add.js`, `multiply.js`, …) при загрузке
  вешает свой слушатель через `emitter.on(...)`. Внутри слушателя он
  сам вычисляет результат и печатает его.
- `index.js` только разбирает аргументы и вызывает `emitter.emit(op, a, b)`.

### `emitter.js`

```javascript
const { EventEmitter } = require('events');
module.exports = new EventEmitter();
```

### `add.js`

```javascript
const emitter = require('./emitter');

emitter.on('add', (a, b) => {
  console.log(a + b);
});
```

### `index.js` (фрагмент)

```javascript
const emitter = require('./emitter');

// ⚡ Важно: модули должны загрузиться,
// чтобы подписаться на события ДО первого emit.
require('./add');
require('./subtract');
require('./multiply');
require('./divide');

const [aStr, bStr, op] = process.argv.slice(2);
const a = Number(aStr);
const b = Number(bStr);

const hasListeners = emitter.emit(op, a, b);
if (!hasListeners) {
  console.error(`Ошибка: обработчик для "${op}" не найден`);
  process.exit(1);
}
```

## 🛡️ Обработка ошибок

Калькулятор сообщает об ошибке и завершается с кодом `1`, если:

- передано не три аргумента;
- одно из чисел не приводится к числу (`NaN`);
- указана неизвестная операция (нет слушателя на такое событие);
- происходит деление на ноль.

Пример:

```bash
$ node index.js 10 0 divide
Ошибка: деление на ноль невозможно

$ node index.js 5 abc add
Ошибка: "abc" не является числом

$ node index.js 5 6 pow
Ошибка: неизвестная операция "pow"
Доступные операции: add, subtract, multiply, divide
```

## 🔌 Как добавить новую операцию

1. Создайте файл `power.js`:

   ```javascript
   const emitter = require('./emitter');
   emitter.on('power', (a, b) => console.log(Math.pow(a, b)));
   ```

2. В `index.js` добавьте `require('./power');` и допишите
   `'power'` в массив `VALID_OPERATIONS`.

3. Готово: `node index.js 2 10 power` → `1024`.

> 💡 `index.js` при этом **не меняет логику расчёта** — он по-прежнему
> просто публикует событие. Это и есть главная выгода событийной модели.

## 🧠 Используемые концепции

- **`EventEmitter`** из модуля `events` — стандартный механизм событий в Node.js.
- **Синглтон через `module.exports`** — один экземпляр emitter на всё приложение.
- **`emitter.on(event, handler)`** — подписка.
- **`emitter.emit(event, ...args)`** — публикация; возвращает `true`,
  если были слушатели, и `false` в противном случае.
- **Слабая связанность (loose coupling)** — `index.js` не импортирует
  конкретные операции, а только публикует события.

## 🔍 Отличия от версии без EventEmitter

| Аспект                  | Без EventEmitter                  | На EventEmitter                          |
|-------------------------|-----------------------------------|------------------------------------------|
| Связь `index → операция`| Жёсткая (`require('./add')`)      | Слабая (только `emitter.emit('add')`)    |
| Кто печатает результат  | `index.js`                        | Сам модуль операции в обработчике        |
| Как добавить операцию   | Правка объекта `operations`       | Новый файл + `require` его в `index.js`  |
| Расширяемость           | Средняя                           | Высокая: можно навесить несколько слушателей |
| Возврат значения        | Функция возвращает число          | `emit` ничего не возвращает (кроме `bool`)|

## ✅ Требования

- Node.js 14+ (достаточно любого LTS).
- Внешних зависимостей нет — используется встроенный модуль `events`.
